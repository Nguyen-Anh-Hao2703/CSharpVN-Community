# 🚀 Tên Dự Án Của Bạn

Dự án này nhằm tạo ra một môi trường cộng đồng ngôn ngữ lập trình C#VN (C# dạng Tiếng Việt) cho mọi người cùng nhau phát triển và học hỏi ngôn ngữ mới nổi này

## ✨ Tính năng nổi bật

- 🔐 Hệ thống đăng nhập vào tài khoản admin
- 📋Nơi mọi người gửi code để phát triển C#VN
- 📱 Giao diện tương thích mọi thiết bị

## 🛠️ Công nghệ sử dụng

- **Frontend:** CSHTML, CSS
- **Backend:** JavaScript, Render
- **Database:** SupaBase

## 📦 Hướng dẫn cài đặt

Làm theo các bước sau để thiết lập dự án trên máy cục bộ của bạn:

1. Clone dự án về máy:
```bash
git clone https://github.com
```
